# 新会话启动文案

> 用法：每开一个新会话整理作品集项目时，把下面代码块整段复制发出去，然后直接开始聊具体项目即可。

```
我在整理个人作品集网站（本地仓库：/Users/zhudi/Desktop/Cat Desk/design-work，线上：design-workbench.top，GitHub：taoznice/design-work）。

背景：这个站已经搭好（Next.js 15 + Tailwind，亮色极简风格），已有 5 个项目条目，其中 2 个有详情页。接下来我会陆续整理十几个项目，每个项目都跟你边聊边梳理：项目的前因后果、设计思路、图片素材。聊完、我确认之后，你帮我把内容沉淀成一篇 KM Wiki——Wiki 是文案的权威版本，先不上线。等所有项目都沉淀完，我会批量回来修改，最后统一从 Wiki 转成 content/portfolio.ts 条目发布。

开始之前，你先读 /Users/zhudi/Desktop/Cat Desk/design-work/docs/projects-index.md，这是全部项目的总索引（项目名 / slug / Wiki 链接 / 状态：讨论中 → 已沉淀 → 待修改 → 已上线），读完你就知道整体进度了。接下来我会直接跟你聊某个项目：如果它在索引里已有 Wiki 链接，你就用 citadel 读回正文恢复上下文；如果没有，就是新项目，从零开始聊。

回写规则（重要）：
- 我确认内容后 → 沉淀或更新 Wiki + 更新总索引里的状态和链接；
- 图片素材我会给你桌面文件夹路径，沉淀时压缩后存入 public/assets/work/<slug>/；
- 我说「发布」时 → 从 Wiki 拉最新内容转 portfolio.ts → 本地验证 → commit + push（push 失败就提示我开 VPN 后重试）；
- 无数据叙事：项目文案不出现任何业务数据指标。
```
